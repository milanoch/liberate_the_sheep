# Ассеты и материалы

## Добавить ассет

Положи файл в `Assets/` — реестр (`.Panda/assets.json`) ведёт РЕДАКТОР: он
регистрирует новые файлы при открытии проекта/рескане и раздаёт id. Реестр руками
не править. Если id нового файла нужен сразу, а редактор ещё не рескинул — попроси
пользователя (реестр обновится, id появится в assets.json).

- Текстуры: `.png/.jpg`. По умолчанию sRGB (цвет); карты ДАННЫХ (normal, roughness,
  шумы) требуют снять sRGB — попроси пользователя переключить в инспекторе текстуры.
- Меши: `.gltf` (+ `.bin` и текстуры рядом). На каждый материал glTF редактор
  создаёт `<имя>.mat` рядом; меши одной папки делят материалы по имени.
- Миры: `.world` (см. panda-world-editing).

## Правка материала (.mat)

JSON `{"inputs": [{"name","type","value"}]}`; `type`: 0 float, 1 uint, 2 vec4,
3 texture (value — asset id, 0 = пусто), 4 color (value — {x,y,z,w}).

- Значения правь свободно; НАБОР и ПОРЯДОК полей — контракт шейдера, не меняй.
- Новый материал создавай через редактор (выбор шейдера заливает шаблон полей).
- Шейдер материала хранится в реестре, не в .mat.

После правок — попроси пользователя нажать Reload (Cmd/Ctrl+R): редактор
перечитает изменённые файлы. Подробнее: PandaSDK `docs/assets.md`.
