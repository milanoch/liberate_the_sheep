# Правка .world

Мир — JSON (`Assets/**.world`). Правь напрямую, затем попроси пользователя нажать
**Reload** (Cmd/Ctrl+R) — редактор синхронизируется с диском (перечитает изменённые
ассеты/скрипты/мир); битый JSON безопасен (ошибка в лог, текущий мир не трогается).
Запускает игру только человек.

## Минимальная сущность

```json
{
    "id": 2847561930,
    "tagComponent": { "tag": "MyEntity" },
    "relationshipComponent": { "parent": 0, "children": [] },
    "transformComponent": {
        "position": {"x":0,"y":0,"z":0},
        "rotation": {"x":0,"y":0,"z":0,"w":1},
        "scale": {"x":1,"y":1,"z":1}
    },
    "scriptListComponent": { "scripts": [] }
}
```

## Правила

- `id` — случайный uint32, уникальный в файле, не 0. Сгенерируй и проверь грепом.
- `rotation` — кватернион (identity = 0,0,0,1), не Эйлеры.
- Иерархия двусторонняя: `children` родителя И `parent` ребёнка. `parent: 0` — корень.
  Позиции детей — в локали родителя.
- Опциональные компоненты (камера, свет, меши, физика...) — просто ключи рядом;
  полный список и точные поля: PandaSDK `docs/world-format.md` и
  `Panda/include/Panda/Serialization/ComponentDtos.hpp`. Незнакомый компонент —
  собери один раз в редакторе, сохрани мир и используй JSON как образец.
- Ссылки на ассеты (меш, текстура, мир) — id из `.Panda/assets.json`.
