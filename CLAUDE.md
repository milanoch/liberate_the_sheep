# liberate_the_sheep — игра на движке Panda

Проект PandaEditor. Всё состояние проекта — текстовые файлы: их можно читать и
править напрямую, работающий редактор подхватывает изменения по явной команде.

## Структура

- `Assets/` — миры (`.world`, JSON), материалы (`.mat`, JSON), текстуры, меши (glTF).
- `Scripts/liberate_the_sheep/src/` — C++-скрипты игры (собираются в библиотеку).
- `.Panda/` — служебное: реестр ассетов (`assets.json`), манифест скриптов
  (`scripts-manifest.json`), куки. Руками не править.
- `Export/` — обвязка сборки standalone-игры.

## Правила работы

- **Запуск и отладку игры выполняет только человек.** Не пытайся запускать
  редактор или игру; попроси пользователя проверить и дать обратную связь.
- **В конце работы попроси пользователя нажать Reload (Cmd/Ctrl+R)** — редактор
  синхронизируется с диском одной командой: перечитает изменённые ассеты, свежую
  скриптовую сборку и мир (по mtime). Битый JSON мира безопасен — редактор сообщит
  об ошибке и оставит текущий мир.
- C++-скрипты собирай сам (см. скил panda-build-scripts) — Reload подхватит
  свежую библиотеку.
- Новые файлы ассетов регистрирует редактор; руками `.Panda/assets.json` не менять.
- Подробные форматы: `docs/` в PandaSDK (world-format.md, assets.md, scripting.md).

## Скилы

- `panda-world-editing` — правка `.world`: сущности, компоненты, id.
- `panda-script-fields` — привязка значений полей скриптов в мире.
- `panda-assets` — добавление ассетов и правка материалов.
- `panda-build-scripts` — сборка скриптовой библиотеки.
